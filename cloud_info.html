Mapping to Cloud Computing Laboratory Syllabus
Syllabus Concept Implementation in Project How to Demonstrate to Examiner
Virtualization AWS EC2 Virtual Machine instance running Linux (Ubuntu 24.04). Show the EC2 instance running on AWS Nitro hypervisor with dedicated vCPU and RAM allocation.
IaaS (Infrastructure as a Service) AWS EC2 compute, Elastic Block Store (EBS) volume, Public Elastic IP, VPC subnet. Show AWS EC2 console with instance type (t2.micro / t3.micro), public IP, security group rules, and SSH terminal.
PaaS (Platform as a Service) Deployable container package suitable for AWS App Runner or Elastic Beanstalk. Explain how managed platforms abstract OS patching, auto-scaling, and web server configuration.
SaaS (Software as a Service) Campus Lost and Found web portal accessible from any browser. Access http://<EC2_PUBLIC_IP>:5000 or port 80 from student mobile/laptop without installing software.
Containerization Dockerfile packaging Python 3.13, dependencies, Gunicorn, and app code. Execute docker ps and docker build commands on the EC2 terminal; show container port mapping 5000:5000.
Cloud Database AWS RDS MySQL managed database instance. Show RDS endpoint in AWS Console; query tables from MySQL client or check data persistence across container restarts.
Cloud Storage Amazon S3 bucket for storing uploaded item photographs. Upload an item image, then open AWS S3 console to show the image object stored in the S3 bucket with direct S3 URL.
Cloud Networking VPC, Subnet, Internet Gateway, Security Groups (Inbound ports 22, 80, 5000). Show AWS Security Group rules restricting DB port 3306 to EC2 while exposing web port 5000 to the internet.
Cloud Security Werkzeug scrypt password hashing, Role-Based Access Control (Admin/Student), IAM access keys. Inspect database to show passwords stored as hashes; verify that non-admin students cannot access admin status controls.
Cloud Monitoring AWS CloudWatch metrics for EC2 and RDS. Open CloudWatch dashboard in AWS Management Console to show live CPU Utilization, Network In/Out, and disk metrics.
